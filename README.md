## 功能

- **区域截图**：悬停自动高亮最上层窗口，单击锁定；也可拖动自由框选，显示像素尺寸并调整选区。
- **截图标注**：文字、矩形和箭头；支持中文、多行文字、六种颜色、线宽与字号。
- **标注编辑**：选择、移动、删除、撤销与重做；矩形支持拖动八个控制点缩放，双击文字可再次编辑。
- **悬浮贴图**：同时放置多张图片，保持置顶；拖动移动、滚轮或触控板捏合缩放。
- **贴图提取文字**：自动在本机识别图片文字，直接在图上选择、全选并复制；右键可复制全部文字。
- **透明度**：按住 Option 滚动调整贴图透明度，可设置新贴图的默认不透明度。
- **图片输出**：复制到剪贴板、保存为 PNG，或直接变成贴图；截图标注合成到最终图片。
- **剪贴板贴图**：支持剪贴板图片或复制的本地图片文件。
- **菜单栏管理**：隐藏／显示全部贴图、关闭全部、修改设置和退出。
- **自定义快捷键**：支持录入组合键、冲突反馈和预设选择。

截图默认包含已有贴图；可以在设置中开启“截图时排除悬图窗口”。

## 安装

1. 下载上方的 `XuanTu-arm64.dmg` 并双击打开。
2. 将磁盘镜像中的 **悬图.app** 拖入 **Applications（应用程序）**。
3. 从“应用程序”打开悬图，随后推出安装磁盘镜像。
4. 首次启动显示设置窗口。关闭设置窗口后，应用仍在菜单栏运行，可通过菜单栏图标或快捷键操作。

### 首次打开提示无法验证开发者

当前安装包采用本地 ad-hoc 签名，尚未使用 Developer ID 发行签名，也未进行 Apple 公证。经浏览器下载后，macOS 可能显示无法验证开发者的提示。

确认文件来自你信任的项目来源后，先尝试打开一次，再进入 **系统设置 → 隐私与安全性**，找到该应用的拦截提示并选择 **仍要打开**，按系统提示确认。不同系统版本的文字可能略有不同。

不要关闭系统整体安全检查。如果系统明确提示检测到恶意软件、文件损坏或安装包校验失败，请停止安装并重新核对来源。

参考：[Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)。

### 录屏权限

区域截图需要系统录屏权限；剪贴板贴图不需要。

1. 首次点击“区域截图”时，按提示打开系统设置。
2. 在 **隐私与安全性 → 录屏与系统录音** 中打开“悬图”开关。部分系统版本称为“屏幕录制”。
3. 按系统要求退出并重新打开悬图，再截图。

应用不需要完全磁盘访问、麦克风或摄像头权限。授权录屏用于截图，当前版本不提供录屏功能。

## 基本使用

### 截图和标注

1. 使用菜单栏“区域截图”或按 **⌥⌘A**。鼠标悬停时高亮当前位置最上层可选窗口，单击锁定；按住拖动则自由框选。
2. 在工具栏选择矩形、箭头或文本。下方可切换颜色、线宽及字号。
3. 矩形画完后可直接拖动边框或框内移动，拖动四角、四边中点的控制点调整大小；点击其他矩形的边框可重新选中。按 **R** 清除当前选择后可继续画框。其他标注使用选择工具选中后拖动移动，按 Delete 删除。
4. 按 **T** 贴图、**回车**复制，或 **⌘S** 保存 PNG。

文本工具点击选区内位置后开始输入。**回车换行，⌘回车完成输入**；Esc 取消本次文字编辑。在文字编辑状态中，字母和回车交给文本编辑器处理，不触发截图工具快捷键。

外层截图范围也可调整：在选择工具下拖动空白处移动，或在非文字输入状态下按住 **空格** 从选区内任意位置拖动移动；四角、四边中点及整条边缘均可拖动缩放，使用标注工具时也能操作。矩形标注的移动、缩放均支持 **⌘Z / ⇧⌘Z** 撤销与重做。调整截图范围时，标注保持原有屏幕内容坐标；编辑控制点和辅助线不会进入最终图片。

如果开启“框选后直接贴图（跳过标注）”，选区完成后会直接生成贴图；需要标注时请关闭该选项。

### 自动选择窗口

在设置中可开关“悬停自动选择窗口”，默认开启。悬停高亮是预览，单击才锁定选区；锁定后移动鼠标不会覆盖选区。Tab / Shift+Tab 切换当前光标下重叠的候选窗口。已有标注时不允许切换，以免丢失编辑内容。

桌面、Dock、菜单、不可见和过小的窗口不参与。已有悬浮贴图可以选中；开启“截图时排除悬图窗口”时，贴图也不参与自动选择。

窗口范围和层级在本次截图开始时固定，与冻结画面对应。跨屏窗口仅选择当前显示器内的部分；导出仍是屏幕当前画面的裁剪，不恢复被遮挡窗口内容。窗口信息仅在内存中使用，不记录标题，不需要新增辅助功能权限。

### 操作贴图

- 单击贴图使其获得焦点；文字区域直接拖动选字，空白区域拖动可移动贴图。贴图获得焦点后，按住空格可从图片任意区域拖动。
- 滚轮或触控板捏合缩放；Option＋滚轮调整不透明度。
- **双击文字选择词语；双击空白区域复制图片并关闭当前贴图**，可以在设置中关闭双击关闭动作。
- **Esc 优先取消文字选择，没有文字选择时关闭贴图；⌘W 始终关闭贴图。**关闭操作不修改剪贴板。
- 鼠标移入时显示操作按钮；右键菜单提供保存、复制、恢复原始大小及适应屏幕等功能。尺寸较小的贴图使用右键菜单。

### 从贴图提取文字

截图生成的贴图和剪贴板贴图都会自动识别文字，识别期间仍可移动、缩放、复制图片或保存。文字识别在本机完成，不上传图片。

- 在文字上拖动选择，按 **⌘C** 复制所选文字。没有文字选择时，⌘C 复制图片。
- 按 **⌘A**，或点击工具栏的“提取文字”按钮，全选已识别文字；右键菜单还可直接“复制全部文字”。
- **⇧⌘C**、工具栏“复制图片”和右键“复制图片”始终复制原图，选字高亮不会进入复制或保存的图片。
- 图片缩放时文字选择位置同步更新。相同贴图隐藏后重新显示时复用识别结果。
- 没有识别到文字或识别失败时，可点击“提取文字”按钮，或从右键菜单选择“重新识别文字”。设备不支持时会在菜单中提示。

中英文优先，实际识别效果取决于图片清晰度、文字排版和系统支持的语言。识别结果只随贴图保留在内存中，关闭贴图后释放。

### 图片保存

图片默认仅保存在运行内存中，不自动建立历史图库。请在关闭或退出前复制或保存需要的图片。退出应用与关闭全部贴图时会提示未保存内容可能丢失；单张贴图的快捷关闭直接执行。

## 更新与卸载

**更新：**先保存需要的贴图并从菜单栏退出悬图，再把新版应用拖入“应用程序”替换旧版。本地签名随构建变化，更新后系统可能要求重新授予录屏权限。应用没有自动更新服务。

**卸载：**从菜单栏退出悬图，将“应用程序”中的悬图移到废纸篓。手动保存的图片不会因此删除。偏好设置使用独立的 `local.xuantu.capture` 域，卸载应用后系统可能保留这些偏好设置。

## 常见问题

**重复提示“允许悬图截取屏幕”？**

确认系统设置中允许的是当前安装的悬图，然后彻底退出并重新打开。若更新后开关已开仍无效，可在系统录屏权限列表移除旧条目，再添加“应用程序”中的当前应用并授权，随后重新启动。请避免同时运行磁盘镜像内和“应用程序”中的两份应用。

**截图没有显示已有贴图？**

在设置中取消“截图时排除悬图窗口”。新安装默认不排除，已有偏好设置会继续保留。

**框选后没有标注工具栏？**

关闭设置中的“框选后直接贴图（跳过标注）”。

**菜单栏图标存在，但没有普通主窗口？**

应用常驻菜单栏，关闭设置窗口不会退出。可从菜单栏打开设置或执行截图。

**贴图关闭后找不到图片？**

当前没有自动历史记录；关闭前请保存或复制。双击空白区域会复制图片后关闭，双击文字用于选词。Esc 有选中文字时先取消选择，否则关闭；⌘W、关闭按钮及右键“关闭”直接关闭，不复制。

**能跨多个屏幕一次框选吗？**

可以在任意显示器分别截图，当前不支持一次跨显示器连续框选。

## 隐私与数据

- 屏幕图像、标注、贴图和文字识别在本地处理；应用没有图片上传、账户或遥测服务。
- 仅在主动触发剪贴板贴图时读取剪贴板；保存目的地由用户选择。
- 图片默认驻留内存，偏好设置使用系统 UserDefaults。
- 不安装后台辅助服务或登录项，不需要完全磁盘访问权限。
- 使用 Apple 系统框架，无第三方代码运行依赖。

## 源码构建

需要 macOS、Apple Command Line Tools（或完整 Xcode），以及支持 macOS 14+ API 的 SDK。无需额外安装包管理器依赖。

在项目根目录执行：

```bash
# 如未安装 Apple 开发工具，先安装；已安装可跳过。
xcode-select --install

# 构建应用，默认输出 .build/悬图.app。
bash build.sh

# 或显式指定输出位置。
bash build.sh "$PWD/dist/悬图.app"

# 生成与 README 下载入口对应的 DMG，并检查镜像完整性。
bash package.sh
```

`build.sh` 使用系统 `swiftc` 编译 VisionKit 文字选择桥接、生成 Objective-C 头文件，使用 `clang` 编译其余源码，再由 `swiftc` 链接 arm64 程序、生成应用图标并进行本地签名。如果目标应用正在运行，脚本会停止，防止重写运行中的程序。

部分 Command Line Tools 升级后会残留重复的 `SwiftBridging` 模块定义。构建脚本会在本次编译的虚拟文件系统中屏蔽旧定义，不修改系统工具链文件。

`package.sh` 会创建包含悬图与 Applications 快捷入口的压缩磁盘镜像，默认输出 `downloads/XuanTu-arm64.dmg`。可以传入目标 DMG 路径；`XT_BUILD_DIR` 可指定中间产物目录。重新生成安装包后，更新校验值：

```bash
(cd downloads && shasum -a 256 XuanTu-arm64.dmg > SHA256SUMS.txt)
```

`.build/`、`dist/`、应用目录及日志不会加入 Git；`downloads/` 中保留当前版本安装包与校验文件，正式发行文件同时发布至 GitHub Releases。

## 当前边界

- 支持 Apple Silicon、macOS 14+；Intel 未提供预编译包。
- 支持贴图 OCR 与原位选字。不包含翻译、录屏、长截图、控件级识别或历史贴图库。窗口自动选择识别普通系统窗口，不细分网页元素。
- 标注在截图阶段编辑；输出为合成位图，变成贴图后不能再单独编辑其中的标注对象。
- 当前发行包为本地签名，未做 Apple 公证。
- 1.3.1 已完成源码编译、签名、安装包完整性与静态代码审阅，用户已确认矩形缩放可用；未运行自动化测试或全面交互回归。不同显示器、输入法和系统版本的表现仍需实际使用反馈。
