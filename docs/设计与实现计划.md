# 悬图 1.0：截图与悬浮贴图（初始计划）

日期：2026-10-16。本文记录首版设计。

此文件保留 1.0 初始范围；后续已批准的标注扩展见《截图标注-1.1设计与计划.md》。

## 目标与范围

交付适配本机 Apple Silicon、macOS 14 及以上系统的独立原生应用与完整源码。实现区域截图、多张悬浮贴图、拖动、缩放、透明度、剪贴板贴图、复制与保存、全部隐藏/显示、菜单栏入口及可配置全局快捷键。不包含录屏、OCR、翻译、长截图、复杂标注或历史贴图库。

支持区域选择、T 贴图、回车复制、右键取消以及圆角贴图。应用使用独立代码、图标与数据配置。

## 行为设计

- 常驻菜单栏。首次打开显示欢迎与设置窗口，之后可从菜单进入。
- 截图：用户主动触发后检查录屏权限；未授权时只提示一次并提供打开系统设置按钮，不循环请求。使用 ScreenCaptureKit 截取显示器图像，生成全屏选区界面。
- 支持多显示器分别框选，选区限制在开始拖动的显示器；Retina 按图像像素与显示点数比例裁剪。
- 选区显示像素尺寸，拖动调整位置，八个控制点调整大小。下方工具条提供保存、复制、贴图、取消。T / 双击贴图，回车复制，Cmd+S 保存，Esc / 右键取消。提供“框选后直接贴图”选项。
- 贴图保持置顶，支持当前及其他桌面空间。拖动移动，滚轮缩放，Option+滚轮调整透明度。悬浮工具条与右键菜单提供复制、保存、缩放重置、透明度、关闭等操作；双击关闭可在设置中关闭。
- 默认快捷键 Option+Command+A / S / H。支持修改与冲突反馈；提供 Option 或 Control 配合 A/S/H 的预设。
- 剪贴板仅在用户主动触发时读取，只接受图片或本地图片文件。截图与贴图仅驻留内存；保存由用户选择目的地，不自动上传，不自动读取旧应用数据。
- App 使用独立 Bundle ID `local.xuantu.capture`。采用本地签名，无共享数据组或登录项配置。后续重新签名的更新可能要求重新授权，不承诺本地签名跨版本权限永远保留。

## 实现架构

Objective-C / AppKit / ScreenCaptureKit / Carbon HotKey。无网络依赖，不启动辅助服务。使用 clang 直接打包，避开本机已知的 Swift 模块映射冲突。源码模块：

| 文件 | 职责 |
| --- | --- |
| Sources/main.m | 应用生命周期入口 |
| Sources/XTCommon.h/.m | 图片复制/保存、通用控件、设置默认值 |
| Sources/XTHotKeys.h/.m | 全局快捷键注册、反注册、冲突及录入 |
| Sources/XTCapture.h/.m | 录屏权限、显示器截图、选区视图与裁剪 |
| Sources/XTPin.h/.m | 独立贴图窗口、缩放、透明度、快捷操作 |
| Sources/XTSettings.h/.m | 欢迎和设置界面、快捷键设置 |
| Sources/XTAppDelegate.h/.m | 菜单栏、各模块协调、显示/隐藏、退出 |
| Resources/Info.plist | 独立应用身份与运行要求 |
| build.sh | 编译、生成图标、打包、本地签名 |
