# 截图选区与矩形标注调整：设计与实施计划

日期：2026-10-30。

目标：截图范围与矩形标注均支持移动和拖拽缩放。用户已确认两种框都需要支持。

## 交互设计

沿用现有 AppKit 鼠标事件与标注模型，不增加依赖。相比强制切回选择工具或增加单独的编辑模式，直接让矩形工具兼容编辑已有矩形，保留连续画框的能力。

- 截图选区：选择工具拖动空白处移动；非文字输入状态下按住空格，可从任意工具移动选区。四角、四边中点与整条边缘均可拖拽缩放，在标注工具下也可操作。
- 矩形标注：画完后保持选中并显示八个控制点；选择或矩形工具下，点击边框选中，拖动边框或已选矩形内部移动，拖动控制点缩放。按 R 清除当前选择后可以继续画框。
- 命中顺序：空格移动选区、已选矩形控制点、截图选区边缘、当前工具的标注操作。文字编辑器和工具栏保持自己的事件处理。
- 缩放使用拖动起始位置的增量，避免在边框附近按下时跳动；对边固定，正在调整的轴最小为 3 个逻辑点，拖动边受截图范围限制；无位移的轴保持原尺寸，兼容原有可画出 2 点宽高矩形的行为。
- 标注移动和缩放各自只产生一条撤销记录；单击或拖回原位不增加记录。控制点和辅助线只在编辑界面显示，不参与贴图、复制或保存。
- 裁剪范围改变时，标注继续保持原有屏幕内容坐标，不跟随截图范围缩放。
