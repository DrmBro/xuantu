# 悬图 1.3.0：贴图文字提取

发布日期：2026-10-26。

截图和剪贴板图片生成贴图后，自动在本机识别文字，可直接在原图上选择并复制，不必另开文字编辑窗口。

## 新增功能

- 在图片文字上拖动选择，双击选择词语；⌘A 或工具栏“提取文字”按钮全选识别文字。
- ⌘C 复制所选文字；无文字选择时复制图片。⇧⌘C 和“复制图片”按钮始终复制原图。
- 右键菜单提供复制所选文字、复制全部文字、全选与重新识别。
- 使用 macOS 原生 VisionKit 本机识别，中英文优先，不上传图片或识别结果。
- 异步识别期间仍可操作贴图；缩放后选字位置同步更新，隐藏再显示时复用结果。

## 交互变化

- 文字区域拖动用于选字，空白区域拖动移动贴图。贴图获得焦点后，空格＋拖动可从任意位置移动。
- 双击文字用于选词；双击空白区域保留“复制图片并关闭”，受原有设置控制。
- Esc 优先取消文字选择，没有选择时关闭贴图；⌘W 始终关闭。
- 滚轮缩放、触控板捏合、Option＋滚轮透明度调整继续可用。图片导出不包含选字高亮或工具栏。

## 构建与兼容

- 支持 Apple Silicon、macOS 14.0 及以上系统；本次提供 `XuanTu-arm64.dmg` 与 `SHA256SUMS.txt`。
- 新增 Swift 与 Objective-C 桥接构建，无第三方运行依赖。
- 修复部分 Command Line Tools 环境下重复 `SwiftBridging` 模块定义导致的构建失败，不修改系统工具链文件。

## 验证与已知事项

- 功能源码已完成本机构建、签名检查和静态审阅，用户已反馈可用；发行包检查磁盘镜像完整性、应用签名、版本与 SHA-256 校验值。
- 按要求未新增测试文件、未运行自动化测试或全面交互回归。
- 当前采用 ad-hoc 本地签名，未使用 Developer ID 签名或 Apple 公证；更新后可能需要重新授予录屏权限。
- 识别结果受图片清晰度、排版和系统语言支持影响。图片与识别结果只随贴图保存在内存中。
