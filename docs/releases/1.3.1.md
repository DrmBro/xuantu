# 悬图 1.3.1：截图选区与矩形标注调整

更新日期：2026-10-30。版本号 1.3.1，构建号 8。

## 功能变化

- 红色等颜色的矩形标注画完后可直接拖动边框或已选框内部移动，八个控制点支持缩放。矩形工具兼容编辑已有矩形，按 R 清除当前选择后可继续画框。
- 矩形移动与缩放分别作为一次操作支持撤销、重做，拖回原位不新增记录。
- 外层截图选区支持四角、四边中点和整条边缘缩放；非文字输入时，空格拖动可从任意工具移动截图范围。
- 增加方向缩放光标，保留按下时的偏移，避免开始缩放时选框跳动。编辑控制点、辅助线不会进入贴图、复制或保存的图片。
- 保留贴图文字识别、原位选字复制及已有截图、标注和导出功能。
