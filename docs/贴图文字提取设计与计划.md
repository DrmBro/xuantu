# 贴图文字提取：设计与实施计划

日期：2026-10-26。

目标：新贴图自动在本机识别图片文字，用户可以直接在图片上选择、全选并复制文字。截图贴图和剪贴板贴图共用这一能力。

## 方案

采用系统 VisionKit 的 `ImageAnalyzer` 和 `ImageAnalysisOverlayView`，通过一个 Swift 控制器向现有 Objective-C 贴图暴露接口。由系统完成文字定位、跨行选择与选择高亮；应用维护图片拖动、缩放、工具栏和快捷键的事件分流。识别只请求文字类型，不增加网络服务或第三方依赖。

另一方案是用 Vision 识别文字后自行绘制选区、实现字级命中与跨行拖选。它能保持纯 Objective-C，但需要额外维护选择交互和复杂排版。本次使用系统选择层，并保留原来的原生应用结构。

## 交互约定

- 贴图显示时自动开始异步识别，结果随该贴图保留在内存中；缩放、隐藏再显示不重复识别。
- 文字区域由系统处理拖选与双击选词，不触发双击复制图片并关闭。空白区域保持拖动贴图和原有双击行为。
- 按住空格可从图片任意区域拖动贴图。工具栏按钮保持可点击。
- 有文字选择时，⌘C 复制选中文字；没有文字选择时，⌘C 复制图片。⇧⌘C 和“复制图片”按钮始终复制原图。
- ⌘A 全选识别出的文字；工具栏增加“提取文字”入口，完成识别后点击可全选文字。右键菜单提供复制所选文字、复制全部文字、全选文字与重新识别。
- Esc 优先取消文字选择；没有文字选择时关闭贴图。⌘W 和关闭按钮始终关闭贴图。
- 图片缩放时同步选择层的尺寸与内容区域。保存和复制图片使用原始图片，不包含识别高亮或工具栏。
- 识别中、没有文字、失败与设备不支持分别显示状态。失败后可以重试；关闭贴图会取消识别并忽略迟到结果。
