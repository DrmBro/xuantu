# 窗口自动选择（1.2.0）

日期：2026-10-19。功能及交互已确认。

## 已确认行为

- 截图开始时获取系统窗口的前后层级与边界，不启动辅助服务，不增加辅助功能权限。
- 悬停时高亮光标处最上层可选窗口；桌面或无候选处清除预览。
- 单击锁定预览为选区并进入已有标注流程；超过拖动阈值则使用自由框选。
- 锁定后鼠标移动不覆盖选区。Tab / Shift+Tab 在当前光标下的候选窗口间切换，切换后选区仍可调整。
- 为避免标注丢失，存在标注或正在编辑文字、拖动时不切换窗口，并提供提示。
- 自动选择默认开启，设置中可关闭。允许选择已显示的悬浮贴图；排除贴图的设置开启时，其窗口也不参与候选。
- 过滤桌面、Dock、菜单、非普通层窗口和过小／透明窗口。只保留本次截图可共享的窗口，保留系统前后顺序。
- 按每个显示器的坐标转换及交集建立候选，跨显示器窗口仅选择当前显示器内可见部分。截图导出仍裁剪当前显示画面，不重建被遮挡的底层窗口。
- 截图界面使用冻结画面，候选同样冻结；悬停不持续枚举后台窗口，不记录窗口标题。

## 实施文件与顺序

- [x] 新增 XTWindowSelection.h/.m，封装系统窗口元数据、显示器坐标转换及按序命中；只枚举元数据，不自行采集像素。
- [x] XTCapture.m 在截图开始时建立候选，在创建遮罩前传给每块显示器的选区视图。
- [x] XTSelectionView.h/.m 增加独立悬停预览与鼠标点击候选，拖动阈值、鼠标离开清理、Tab 切换和锁定状态保护。
- [x] XTCommon.m 默认值、XTSettings.m 设置布局、版本与 README 同步更新。
- [x] 静态审查鼠标生命周期、坐标、候选过滤及现有标注兼容性；执行交付必要编译、包与签名检查。
- [x] 单独准备最新应用及 DMG；未启动界面，不进行 computer use。正式替换需确保退出，不覆盖运行中的文件。
