# 悬图 1.1 截图标注

用户已确认：增加文本、矩形框、箭头，支持颜色、线宽、字号，撤销／重做，以及选中后移动或删除；所有标注进入贴图、复制和保存的最终图像。

## 交互

框选后出现双行工具栏。第一行包含选择、矩形、箭头、文本、撤销、重做、删除及原有输出动作；第二行包含常用颜色、线宽和字号。选择工具维持原有选区调整功能，并支持点击命中标注、拖动移动、Delete 删除。矩形与箭头由拖动生成；文本在选区内点击后原位输入，回车换行，Command+Return 或点击工具栏完成文字编辑。中文输入法的组合输入不能触发贴图或导出快捷键。

文本双击可重新编辑。颜色与尺寸应用于当前选中标注，同时成为后续新标注的默认值。撤销栈按完整操作记录，不为鼠标移动的每一帧建立记录。切换显示器新建选区时清空前一个显示器的标注，避免坐标混用。已有标注时选区外点击不会销毁标注，重新开始截图会建立新的标注上下文；在已有选区边缘调整裁剪范围时，标注保持屏幕内容坐标。

默认截图继续显示工具栏；沿用已存在的“框选后直接贴图”选项。快捷键保持 T 贴图、回车复制、Command+S 保存；新增 V 选择、R 矩形、A 箭头、X 文本、Command+Z 撤销、Shift+Command+Z 重做。文字输入期间正常编辑文本，Command+S 可先提交文本再保存。
